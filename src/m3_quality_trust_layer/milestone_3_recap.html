Code decides

Every check ends in one of three outcomes.

A check is a query that returns the bad records. What happens next is a fixed rule for that check, applied by code. Only records that are certainly wrong are removed without asking a person.

Passthe check found nothingThe totals check
Quarantinecertainly wrong: set aside, kept for inspection22 extra copies
Needs reviewdoubtful: stays in the figures, with a warning4 findings

Kept plus quarantined equals every record. And after the calculation, every total in the profit table matches the kept records. The trail water bottle's profit moved from $5,188.20 to $5,156.94, the figure you worked out by hand.

What you learned

Five more things an AI data engineer knows.

  1. A list goes stale. A check runs every time.The hand-written list had three problems on it. The records held seven. A person finds what they think to look for; a check finds what it was written to find, on every run.
  2. Prove a check both ways.Each check had to find a problem you planted and find nothing in clean records, including the edge case, such as a refund exactly equal to its line.
  3. Remove only what is certainly wrong, and reconcile.Extra copies were quarantined. A large refund or an odd date was left for a person. Nothing was deleted, and a totals check proved nothing was lost on the way.
  4. Code decides. AI explains.The agent read seven messy cases and wrote reports a person can act on. It could not change a record or an outcome, and a report that could not be read was left for a person.
  5. Measure, then read what the model actually did.The harness went from 0 of 7 to 7 of 7 with one sentence. New questions showed the analyst failing in ways no test had caught, and the raw replies showed why. The verifier gained a check.

Lineage and run history

Right now, when the analyst shows evidence, it shows a sample of records. Nobody can say exactly which records, and which run of the pipeline, produced a figure. Next, every figure becomes traceable.

  • Each run of the pipeline is recorded, so two runs can be compared.
