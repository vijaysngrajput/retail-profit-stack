AI explains, and is measured

Fourteen questions. Two versions of the analyst.

One version had the new compare_runs tool and one did not. Each answered all fourteen questions twice, with a trace kept for every answer. These figures are from the runs made when this lab was built. Yours will differ a little.

Without the run tool22 of 28 right
With the run tool25 of 28 right
0.73 → 0.94kappa: agreement on the confidence level, beyond chance
$1,200 → $600cost of mistakes, for 28 answers

Bars show answers with every check passed. Without the tool, the analyst declined all six questions about a change between runs: the honest answer, and $200 each for a person to answer. With it, all six were right. The ten older questions scored 20 of 20 without the tool and 17 of 20 with it, too few to be sure the tool caused that, and exactly what an experiment is there to show. Kappa is the average of two runs. No answer cost more than $200, because the verifier stopped the ones that would have.

What you learned

Five more things an AI data engineer knows.

  1. Lineage is the transformation without the adding up.The calculation keeps one row per product and month. Lineage keeps one row per record. Add the lineage up again and you must get the figure. If you do not, the lineage is wrong.
  2. Keep every run, and fingerprint what went in.The same inputs, code, and settings give the same figures. So when a figure moves, one of them moved first, and the run records show which.
  3. Look it up. Do not guess.Given only two figures, a model could subtract them and could only guess the reason. Given a tool that compares the runs, it repeated what code had worked out. Without the tool, its honest answer was to decline.
  4. A trace is lineage for an answer.Lineage records how a figure was made. A trace records how an answer was made: each model call and tool call, with its input, output, time, and cost. You built one by hand before Langfuse kept them.
  5. Score an agent in more than one way, then read the failures.Accuracy flattered an analyst that always said "high". Kappa and the cost of mistakes did not. The experiments also found two old weaknesses nobody had measured. Reading the failed answers showed the cause of each.

Raw data and ingestion

Right now the business's records are tables that a generator writes in one go. In a real business they arrive as files, again and again, and the files change. Next, the records are loaded by a repeatable process.

  • Loading the same file twice does not duplicate its records.
  • A renamed, added, or missing column is noticed and handled by a rule.
  • Every load is recorded in the run history you just built.
