The requirement

One question, in plain language.

“Which products and categories generated the most contribution profit last month, what changed, and how confident should I be in those numbers?”

The business requirements document said a good answer must contain six things.

  • A headlineThe answer in a sentence or two
  • The figuresEach with its month, product or category, and source
  • The definitionWhich metric definition was used, and its version
  • The assumptionsWhat shapes the figures
  • The data problemsAnything known that affects the figures
  • A confidence levelHigh, medium, or low, with reasons

What you learned

Five things an AI data engineer knows.

  1. Know the right answer before you ask the AI.You started from the business requirement and worked the answer out by hand. Without an answer key, you cannot tell a correct answer from a confident one.
  2. A structured reply is something code can use.A plain call returns text to read. A structured call returns a filled-in form, with every number in its own labelled slot, ready to be checked.
  3. An agent is a model, with tools, in a loop.The model never runs anything. It asks, your code runs the tool, and you reply. LangChain writes the tool descriptions and runs that loop for you.
  4. Right this time is not the same as trustworthy.A capable model got every figure right from a pasted table. But you could not trace a number, check it without a key, or rely on it at a larger scale.
  5. AI drafts and explains. Code decides and checks.AI drafted the metric definitions and wrote the answer. A person fixed the definitions, code calculated every figure, and a verifier checked the result.
